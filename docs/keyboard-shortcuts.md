# キーボードショートカット

thisthat のショートカットの一覧です。最初の表のものはウィンドウ内のどこからでも機能します。特定のペインをあらかじめクリックする必要はありません。

## アプリ内

### 比較する

| ショートカット | 動作 |
|---|---|
| `Ctrl+Enter` | 比較 |
| `F5` | 比較 |
| `Ctrl+S` | [結果を HTML で保存](saving-html.md) |

どちらかの **名前** 欄で `Enter` を押しても比較が実行されるので、名前を入力してそのまま実行できます。

### 変更箇所を移動する

| ショートカット | 動作 |
|---|---|
| `F3` | [次の変更](navigating-changes.md) |
| `Shift+F3` | 前の変更 |
| `Ctrl+Down` | 次の変更 |
| `Ctrl+Up` | 前の変更 |

どちらの方向も端で折り返します。移動すると変更箇所の全体が選択されるので、直後に `Ctrl+C` を押せばその箇所がそのままコピーされます。

### 文字サイズ

| ショートカット | 動作 |
|---|---|
| `Ctrl+plus` または `Ctrl+=` | 拡大 — カーソルがあるペイン |
| `Ctrl+minus` | 縮小 — 同上 |
| `Ctrl+0` | そのペインを既定のサイズに戻す |
| `Ctrl+スクロール` | 拡大／縮小 — **マウスポインタ**があるペイン |

結果ペインは A・B とは別に独自のサイズを保持します。[結果を読む](reading-the-result.md#文字サイズ)を参照してください。両方のサイズは次回起動時まで記憶されます。

### 結果ペイン内

結果ペインは読み取り専用ですが、選択とコピーは通常どおり機能します。

| ショートカット | 動作 |
|---|---|
| `Ctrl+C` | 選択範囲をコピー |
| `Ctrl+A` | 結果全体を選択 |
| 矢印キー | キャレットを移動 |
| `Shift` ＋矢印キー | 選択範囲を拡張 |

入力と貼り付けは無視されます。

### ダイアログ内

| ショートカット | 動作 |
|---|---|
| `Enter` | OK／確定 |
| `Escape` | キャンセル |

[設定](preferences.md)ダイアログと、保存後に表示されるダイアログの両方に当てはまります。

## エクスポートした HTML ページ内

[保存したページ](saving-html.md)には独自のナビゲーションがあり、F3 は意図的に**使いません**。F3 はブラウザー自身の検索機能のものだからです。

| ショートカット | 動作 |
|---|---|
| `n` | 次の変更 |
| `p` | 前の変更 |
| 結果内をクリック | `n` と `p` が続きを始める位置を設定する |
