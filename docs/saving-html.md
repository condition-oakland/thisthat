# HTML で保存する

［**HTML 保存…**］は、結果を**単体の `.html` ファイル**として書き出します。1 ファイルだけで、付随するものはなく、アセットのフォルダーもできません。どのマシンのどのブラウザーでも開けるので、そのままメール添付・保管・アーカイブができます。

**Ctrl+S** でも同じことができます。まだ何も比較していない場合は、空のページを保存するのではなく、その旨を伝えます。

## 保存ダイアログとその後

ファイルダイアログはファイル名の候補（[後述](#ファイル名の候補)）を提示し、拡張子は `.html` が既定になります。

ファイルが書き出されると、次にどうするかを尋ねる小さなダイアログが開きます。

| 選択肢 | 効果 |
|---|---|
| **ファイルを開く** | 既定のブラウザーで開く |
| **フォルダーで表示** | ファイルを選択した状態でフォルダーを開く |
| 両方 | 両方チェックできます。互いに独立しています |
| どちらも選ばない | ダイアログを閉じるだけ |

［**キャンセル**］とダイアログの **X** は、どちらもそれ以上何もしません。いずれの場合もファイルはすでに書き出されています。

ステータス行に保存されたファイル名が表示されます。

## エクスポートされたページの内容

ページは、画面で見ていたものを忠実に写したものです。

- 上部の ~~this~~<u>that</u> **ワードマーク**と、その横の見出し
- 2 つの側の名前を示す **A** と **B** のチップ
- **要約** — 変更箇所の件数、削除・挿入された文字数、または *差分なし*
- **結果そのもの** — ウィンドウとまったく同じマークアップ
- 下部の**凡例** — 取り消し線と下線の意味の説明

### 配色は焼き込まれます

ページは、**実際に見ていた配色とライト／ダークの選択**を使います。ブラウザーのダークモード設定に委ねるのではなく、ファイル内に書き込まれます。ダークモードで読んでいた比較結果は、来月開いても同じように読めますし、送った相手にも同じように見えます。

これは[自分で変更した配色](preferences.md#色)にも当てはまります。エクスポートは出荷時の既定値ではなく、あなたのパレットに従います。

### 言語も焼き込まれます

アプリが日本語の状態で保存した比較結果は、**タイトル・見出し・凡例が日本語**になります。そのため、保存したときにウィンドウがそう読めたとおりにページも読めます。[設定](preferences.md#表示言語)を参照してください。

言語設定が決して触れないのは、比較対象のテキストです。それは常にあなた自身のものです。

## ブラウザーで変更箇所を移動する

エクスポートされたページは、ウィンドウの［**次の変更 ▶**］／［**◀ 前の変更**］バーを備えています。スクロールしてもブラウザーウィンドウの**上端に固定**されます。同じ変更が同じ順序で、同じカウンターとともに並び、現在いる箇所は枠線で示されます。

ブラウザーでのキーは F3 ではなく **n** と **p** です。F3 はブラウザー自身の検索機能のものであり、ページがそれを奪う筋合いはありません。

### 現在位置から移動します

ウィンドウと同様に、ページは前回どこで止まったかではなく、**現在いる位置**から移動します。

- **結果のどこかをクリック**するとキャレットが現れ、**n** はそこから続きます。
- **一節を選択**すると、［次の変更］はその末尾より後ろから、［前の変更］はその先頭より前から始まります。
- **スクロールしただけでクリックしていない**場合は、［次の変更］はウィンドウ上端より下にある最初の変更に移動します。たいていそれが、探そうとしていた箇所です。

### スクリプトについて

ナビゲーションバーは、このページの**唯一の**スクリプトです。ファイル内の他のすべてと同じくインラインで書かれており、それがなくてもページは問題なく読めます。スクリプトを無効にしても失われるのはナビゲーションだけです。

バーは**印刷されません**。キャレットも印刷されず、現在の変更箇所を示す枠線も印刷時には外れます。つまり印刷したものは比較結果そのものになります。

## 2 つの側に名前をつける

各ボックスの上の **名前** 欄に入力した内容は、エクスポートされたページに焼き込まれます。

- ページの**タイトル**
- **ヘッダー**の A・B チップの横
- **凡例** — 「A（this）にのみある文字」ではなく「契約書 v1 にのみある文字」と表示されます

名前は任意です。名前のない側は従来どおりの汎用的な表現になり、片方だけ名前をつけることもできます。

比較そのものは名前を一切参照しません。エクスポート専用です。[比較を実行する](comparing.md#2-つの側に名前をつける)を参照してください。

## ファイル名の候補

両方の側に名前がある場合、保存ダイアログは `Contract-v1-vs-Contract-v2.html` のような候補を提示します。

名前はまずファイル名として安全な形に縮められます。英数字・ハイフン・アンダースコア以外はすべて落とされます。したがって記号・空白・日本語はここを通り抜けられません。その結果として使えるものが残らなかった場合は、汎用の **`thisthat-result.html`** になります。

候補はあくまで候補です。好きな名前を上書きして入力してください。
