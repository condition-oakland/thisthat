# はじめに

このページでは、thisthat の入手と起動、そしてウィンドウの構成を説明します。

## ダウンロード

[最新版をダウンロード](https://github.com/condition-oakland/thisthat/releases/latest){ .md-button .md-button--primary }

上記ページの **Assets** の一覧に `thisthat-vX.Y.Z.zip`（exe とライセンスファイル）があります。このリンクは常に最新のリリースを指すので、ブックマークするならこちらにしてください。個々の zip のアドレスは、次のバージョンが出た時点で古くなります。

[ソースから](#ソースから)実行する場合は、ダウンロードは不要です。

## アプリを起動する

thisthat の実行方法は 2 つあり、どちらでも動作は同じです。

### スタンドアロンの .exe

配布用の zip には **`thisthat.exe`** と `LICENSE.txt`、`NOTICE.txt` が入っています。好きなフォルダーに展開して exe をダブルクリックしてください。インストールは不要で、exe のあるフォルダーには何も書き込まれません。[設定](preferences.md)はユーザープロファイル側に保存されます。

1 ファイル形式の exe はプログラムが動き出す前に自身を展開する必要があるため、ダブルクリックした瞬間から**スプラッシュ画面**（ワードマークのみ）が表示されます。本体のウィンドウが描画されると同時に消えます。

### Windows SmartScreen の警告

thisthat にはコード署名がないため、ダウンロードした exe を初めて実行するとき、Windows は青い画面で「**WindowsによってPCが保護されました**」と表示します。画面に出ているボタンは［**実行しない**］だけですが、［**詳細情報**］をクリックすると、その下に［**実行**］ボタンが現れます。

これは「既知の発行元からのファイルとして十分な実績がない」という Windows の判断であり、ファイルを調べて問題が見つかったという意味ではありません。この画面を出さないようにするにはコード署名証明書が必要で、thisthat はまだ取得していません。

Windows が保証しないものを実行するよう求められているのですから、**ダウンロードしたファイルを確認してください**。各リリースは zip の **SHA-256** をリリースノートに掲載しています。手元のファイルと照合してください。

```
Get-FileHash thisthat-vX.Y.Z.zip
```

一致しない場合は実行せず、[Issue トラッカー](https://github.com/condition-oakland/thisthat/issues)で知らせてください。

この画面を経由したくない場合は、[ソースから](#ソースから)実行してください。Python スクリプトは SmartScreen の対象外です。

### 何も外部に送信されません

秘密性の高い草稿を貼り付ける前に知っておく価値のあることとして、**thisthat にはネットワーク通信のコードが一切ありません。** テレメトリも、更新確認も、クラッシュレポートもありません。比較はすべて自分のデスクトップ上のプロセス内で完結し、それを変えうる Python 標準ライブラリ以外の依存関係もありません。書き込まれるファイルは、明示的に保存した HTML と[設定](preferences.md#選択内容の保存場所)だけです。

一つだけ注意が必要なのは[保存した HTML](saving-html.md#エクスポートされたページの内容)で、これには 2 つのテキストの全文が含まれます。元になった文書と同じだけ秘密性を持つものとして扱ってください。

### ソースから

Python が入っている場合は、**`thisthat.bat`** をダブルクリックするか、次を実行します。

```
python thisthat_app.py
```

比較したい 2 つのファイルを引数として渡すと、それぞれの側に読み込まれた状態で起動します。

```
python thisthat_app.py old.txt new.txt
```

必要なのは **Python 3.9 以降**（tkinter 付き）だけです。`pip install` するものもビルドするものもありません。起動は実質的に瞬時で、ソースから実行する場合はスプラッシュ画面も出ません。

!!! keypoint "覚えておきましょう"
    どちらの方法でも同じプログラム・同じ設定ファイルを使うので、自由に行き来できます。配色・言語・文字サイズはそのまま引き継がれます。

## ウィンドウの構成

ウィンドウは、ツールバー・3 つのテキスト領域・ステータス行で構成されています。

### ツールバー

上部に、左から順に並んでいます。

| コントロール | 機能 |
|---|---|
| **A を読込… / B を読込…** | 片側をファイルから読み込む |
| **入れ替え** | A と B を入れ替える |
| **クリア** | 両方のテキスト・名前・結果をすべて空にする |
| **比較単位** | 比較の粒度 — [比較のオプション](comparison-options.md)を参照 |
| **大小文字を無視** | `Hello` と `hello` を同じものとして扱う |
| **空白を無視** | スペースやタブを差分として数えない |
| **比較** | 比較を実行する — 右側の青いボタン |
| **HTML 保存…** | 結果を単体の HTML ページとして書き出す |

ウィンドウの中で色がついているボタンは［**比較**］だけです。他がすべてグレーなのは意図的なもので、目的の動作を行うボタンこそ最初に目に入るべきだからです。

### 2 つの入力ボックス

左が **A — this**、右が **B — that** です。A に元のテキスト、B に変更後のテキストを入れます。各ボックスの上には **名前** の入力欄があります。これは任意で、[エクスポートした HTML](saving-html.md) にのみ影響します。

### 結果ペイン

入力ボックスの下、ウィンドウの下半分を占めます。専用のバーには次のものが並びます。

- **◀ 前の変更** と **次の変更 ▶**、およびカウンター — [変更箇所を移動する](navigating-changes.md)を参照
- **文字サイズ** と **A−** / **A+** — [結果を読む](reading-the-result.md)を参照

入力ボックスと結果ペインの間の仕切りはドラッグで動かせます。A と B の間の仕切りも同様なので、作業しているペインを広く取ることができます。

### ステータス行

最下部にあります。比較前は次に何をすべきかを示し、比較後は要約（変更箇所の件数、削除・挿入された文字数）、または 2 つのテキストが同一である旨を強調表示で伝えます。

**設定…** はステータス行の右端にあります。[設定](preferences.md)を参照してください。
