# 設定

ウィンドウ右下の［**設定…**］を押すと、3 つの項目を持つダイアログが開きます。インターフェイスの**言語**、**ライト／ダーク**の切り替え、そして 4 つの差分色それぞれの**色**の選択です。

変更は**操作したその場で**ウィンドウに反映されるので、すでに画面に出ている比較結果に対して確かめることができます。

| ボタン | 効果 |
|---|---|
| **OK** | 変更を確定する |
| **キャンセル** | 開始時の状態にそのまま戻す |
| **既定値に戻す** | **編集中のテーマ**について、出荷時の配色に戻す |

いつもどおり、**Escape** でキャンセル、**Enter** で確定です。

## 言語

インターフェイスは **English** と **日本語**が用意されています。

選択は**即座に**反映されます。ウィンドウは中身をそのままに、ラベルだけが張り替えられるので、何も失われません。2 つのテキストと結果はそのままの位置に残ります。選択は次回まで記憶されます。

言語は **HTML エクスポート**にも及びます。アプリが日本語の状態で保存した比較結果は、タイトル・ヘッダー・凡例が日本語になり、保存したときにウィンドウがそう読めたとおりにページも読めます。[HTML で保存する](saving-html.md#言語も焼き込まれます)を参照してください。

この設定が決して触れないのは、比較対象のテキストです。それは常にあなた自身のものです。

!!! keypoint "覚えておきましょう"
    アプリは **English** の状態で出荷され、あなたが選ぶまでそのままです。システムロケールから推測することはしません。ボタンが何語であるかは、読む人の好みであってマシンの属性ではないからです。

## テーマ

**ライト**と**ダーク**があります。

テーマを切り替えると**ウィンドウアイコン**の墨も黒と白で入れ替わり、マークがタイトルバーに沈み込まずに見える状態を保ちます。Windows ではタイトルバー自体もテーマに追随します。

[エクスポートしたページ](saving-html.md#配色は焼き込まれます)はこのテーマで書き出されるので、保存した後ではなく前に設定しておくとよいでしょう。

## 色

変更できる色は 4 つです。

| 設定項目 | 対象 |
|---|---|
| **削除された文字** | 取り消し線が付いた文字そのもの |
| **削除のハイライト** | その背後の帯 |
| **挿入された文字** | 下線が付いた文字そのもの |
| **挿入のハイライト** | その背後の帯 |

いずれかをクリックするとシステムのカラーピッカーが開きます。タイトルには、どの色のどのテーマを編集しているかが表示されます。

!!! keypoint "覚えておきましょう"
    **ライトとダークはそれぞれ独自の配色を保持します。** 一方を設定しても他方は変わりませんし、［**既定値に戻す**］は現在編集中のテーマだけを戻します。両方を出荷時の状態に戻したい場合は、それぞれで実行してください。

### プレビュー

ダイアログの**プレビュー**行には、1 語が削除され別の 1 語が挿入された短い文が表示されます。4 つの色を 1 つずつではなく*組み合わせで*確認できるので、ハイライトの上で文字が読めるかどうかを判断できます。これを知る方法は他にありません。

プレビューの文はインターフェイスの言語で書かれています。この機能の目的は、実際にハイライトを通して読むことになる文字体系に対してハイライト色を判断することだからです。

### 既定値が派手な理由

出荷時の配色は意図的に鮮やかにしてあります。落ち着いたパステルは上品に見えますが、走り読みには向きません。長い比較結果をざっと見ていくとき、変更された部分には主張してもらう必要があります。ハイライト上の文字色は単純な黒ではなく、そのハイライト自体の濃い色調にしてあります。そうすることで、変更部分が単に色の付いた帯ではなく、文字として読める状態を保てます。

派手すぎると感じたら変更してください。そのための設定です。

## 選択内容の保存場所

すべて — 言語、テーマ、色、そして 2 つの[文字サイズ](reading-the-result.md#文字サイズ) — が次回起動時まで、次の場所に記憶されます。

```
%APPDATA%\thisthat\settings.json
```

`%APPDATA%` がないプラットフォームでは、代わりに `~/.config/thisthat/settings.json` になります。

**このファイルを削除すると既定値に戻ります。** 壊れたファイルや手で編集したファイルは、致命的なエラーにはならず無視されます。読み込み時にすべての値が検証され、認識できないものは静かに捨てられるので、不正な設定でアプリが起動しなくなることはありません。

!!! keypoint "覚えておきましょう"
    このアプリが **difff** という名前だったときに使っていた場合、配色は今も `%APPDATA%\difff-desktop\` に残っています。thisthat は自分の名前のフォルダーに何も見つからなかった最初の 1 回だけそれを読み、現在の場所へ引き継ぎます。古いファイルは削除せずディスク上に残します。古いバージョンのアプリがまだインストールされている可能性があり、設定は勝手に捨てていいものではありません。

設定ファイルが書き込めない場合 — プロファイルがロックされている、ディスクが満杯など — thisthat はそれを伝えて処理を続けます。選択内容はその作業中は有効ですが、セッションを越えては残りません。
